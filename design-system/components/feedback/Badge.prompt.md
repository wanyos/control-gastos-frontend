**Badge** — compact status pill. Tone carries meaning: `positive` ingreso/al día, `negative` gasto/impago, `warning` pendiente, `info` programado.

```jsx
<Badge tone="positive" dot>Al día</Badge>
<Badge tone="warning" variant="soft">Pendiente</Badge>
<Badge tone="brand" variant="solid">Premium</Badge>
```

Variants `solid` / `soft` (default) / `outline`.
